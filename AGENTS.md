## Agent skills

### Issue tracker

Issues live in GitHub Issues on `Prevasum/.github`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Categories are the org's issue types, and states are `status:` labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
